# COOKRATE Bot — помощник канала в Telegram

Бот, который помогает выпускать публикации канала **COOKRATE «Необычная Кухня»**:
написать статью и пост, собрать иллюстрации и обложку, сделать ролик-тизер и озвучку,
проверить текст линтером канала и положить черновик прямо в `dzen/next/`.

Он не «общий чат-бот с промптом про еду». Он вшит в репозиторий: берёт правила тона
из `dzen/channel.md`, правила стиля кадра из `dzen/angela.md`, а проверки — из
`dzen/tools/cookrate.py`. Поменяли требование в репо — бот уже работает по-новому,
в Telegram ничего править не нужно.

## Что умеет

| Команда | Что делает |
|---|---|
| `/статья <тема>` | Статья-разбор 2500–3500 знаков по каркасу канала (крючок → продукты → пошагово → «почему работает» → замены → «так не делайте» → подача) |
| `/пост <тема>` | Короткий пост «необычно, но дёшево» с ценой порции |
| `/ролик <тема>` | Раскадровка 45–75 сек + **озвучка** + **тизер-видео** одним заходом |
| `/обложка` | 16:9: кадр-референс + подпись капсом в «ёлочках» по правилу `angela.md` |
| `/кадры` | 3 иллюстрации по промпту Анжелы (через OpenAI или Replicate) |
| `/промпт` | Готовый промпт кадра — вставить в любую нейросеть руками |
| `/тизер`, `/тизер9` | Слайдшоу из кадров: 16:9 и вертикаль 9:16, с озвучкой поверх |
| `/озвучка` | Русский голос (edge-tts: Svetlana/Dmitry) из блока «Текст за кадром» |
| `/проверь` | Линтер по всем `dzen/next/*.md` |
| `/план [неделя]` | Что выходит по контент-плану |
| `/черновик` | Последний сгенерированный текст |
| `/статус` | Что подключено: LLM, картинки, видео, ffmpeg, озвучка |
| `/id` | Ваш chat id (для `TELEGRAM_ADMIN_ID`) |

Инлайн-кнопки под каждым текстом: переписать, проверить, сохранить в репозиторий,
обложка, кадры, тизер, озвучка.

## Три шага до запуска

```bash
python bot/install.py             # 0. проверит Python, создаст .venv, поставит зависимости,
                                  #    спросит токен, сам создаст bot/.env и прогонит самотест
```

```bash
cp bot/.env.example bot/.env      # 1. вписать токен и admin id (если ставили руками)
bash bot/run.sh                   # 2. venv + selftest + запуск
# или в Docker (там уже есть ffmpeg и шрифт с кириллицей):
docker compose -f bot/docker-compose.yml up -d --build   # 3.
```

Токен: [@BotFather](https://t.me/BotFather) → `/newbot` → скопировать.
Свой id: запустить бота, написать `/id`.

Флаги установщика: `--check` (только проверка), `--token … --admin …` (без вопросов),
`--docker` (подсказать команды Docker), `--no-venv`, `--force-env`.
Пошаговый разбор для тех, кто ставит впервые, — в `dzen/SETUP-telegram.md`.

## Что работает без ключей, а что нет

| Возможность | Без `.env`-ключей | С ключом |
|---|---|---|
| Каркас статьи/поста/раскадровки | ✅ собирает структуру по ДНК канала + вопросы автору | — |
| Линтер и «сохранить в dzen/next/» | ✅ всегда | ✅ |
| Готовый текст «под публикацию» | ❌ | `LLM_API_KEY` + `LLM_MODEL` |
| Обложка (референс + подпись) | ✅ если в системе есть ffmpeg | ✅ |
| Иллюстрации-кадры | ❌ покажет готовый промпт | `IMAGE_PROVIDER=openai` или `replicate` |
| Тизер из кадров | ✅ ffmpeg-слайдшоу | `VIDEO_PROVIDER=replicate` — генерация видео |
| Озвучка | ✅ `pip install edge-tts` (нужен выход в интернет) | — |

Логику «работает всегда» я держал специально: бот должен быть полезен и без подписок —
как редактор-структурщик и сборщик обложек. ИИ включается одним ключом в `.env`.

## Провайдеры

**Текст.** Любой OpenAI-совместимый эндпоинт или Anthropic:

```
LLM_FORMAT=openai
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
LLM_API_KEY=sk-...
```

Варианты: `LLM_BASE_URL=https://openrouter.ai/api/v1` с `LLM_MODEL=openai/gpt-4o-mini`
(одним ключом — много моделей), локальная модель через Ollama:
`LLM_BASE_URL=http://127.0.0.1:11434/v1`, `LLM_MODEL=qwen2.5:14b`, `LLM_API_KEY=ollama`.
Anthropic: `LLM_FORMAT=anthropic`, `LLM_BASE_URL=https://api.anthropic.com/v1`.

**Картинки.** `IMAGE_PROVIDER=openai` (gpt-image-1, ключ тот же) или
`IMAGE_PROVIDER=replicate` + `REPLICATE_API_TOKEN` + `IMAGE_MODEL` (например
`black-forest-labs/flux-1.1-pro`).

**Видео.** `VIDEO_PROVIDER=replicate` + `VIDEO_MODEL` (SVD / Wan / Kling — что
доступно по вашему токену).

## Безопасность

* `.env` с токеном в git не попадает — он в `.gitignore`; в образ кладётся только
  `bot/.env.example`.
* Пуск только для своих: `TELEGRAM_ADMIN_ID` (и/или `TELEGRAM_ALLOWED_CHATS`) —
  чужие сообщения бот игнорирует.
* Бот пишет файлы только в `dzen/next/` и во временную папку `bot/.tmp/`,
  `git commit`/`push` не делает: публикация остаётся вашим ручным действием
  (правило №1 в `AGENTS.md`).
* Наружу бот ходит только в API, перечисленные в `.env`. Без ключей сеть не нужна
  вообще, кроме озвучки edge-tts.

## Как устроен код

```
bot/
  config.py     env → один объект Config + флаги «что доступно»
  llm.py        промпт из channel.md, запрос к модели, локальный генератор каркасов
  media.py      OpenAI/Replicate картинки и видео, ffmpeg-обложка и тизер, TTS
  repo.py       нумерация, slugify, запись в dzen/next/, линтер (импорт cookrate.py)
  handlers.py   команды, кнопки, FSM
  __main__.py   `python -m bot` и `python -m bot --selftest`
```

`python -m bot --selftest` — офлайн-проверка сборки: конфиг, генерация каркаса,
линт, транслитерация слага, подпись обложки, доступность ffmpeg. Прогоняется и при
сборке Docker-образа, чтобы кривая конфигурация падала до первого сообщения в чате.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| `TELEGRAM_BOT_TOKEN пуст` | не создан `bot/.env` |
| Обложка: «в контейнере нет ffmpeg» | вы запустили без Docker: `apt install ffmpeg fonts-dejavu-core` |
| Обложка: «не найден шрифт с кириллицей» | поставить `fonts-dejavu-core` или указать `COVER_FONT` |
| Озвучка молчит | нет сети до `speech.platform.bing.com` или `pip install edge-tts` |
| Кадры: `IMAGE_PROVIDER=none` | включить провайдера в `.env`, либо брать `/промпт` и генерировать руками |
| Черновик не появился в репо | `COOKRATE_REPO` указывает не туда; в Docker — проверить том `../dzen:/app/dzen` |
