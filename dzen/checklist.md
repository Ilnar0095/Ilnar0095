# Чек-лист перед публикацией

Прогонять по каждому тексту. 4 минуты, зато без «пост опубликовали, а цену забыли».

## Текст

- [ ] Заголовок 45–60 символов; читается в превью на телефоне целиком.
- [ ] Есть число: ₽, минут, °C, количество порций.
- [ ] Первый абзац — возражение читателя + обещание его закрыть. Не «в этой статье…».
- [ ] Список продуктов с граммами и ценой **всего блюда**.
- [ ] Шаги: один шаг = один глагол + один срок. Никаких «довести до готовности».
- [ ] Блок «почему работает» — 3–5 строк про вкус. Это фирменное, его не вычёркиваем.
- [ ] Блок «если нет X» — чем заменить, чтобы рецепт не развалился.
- [ ] Блок «так не делайте» — 2–3 конкретных запрета.
- [ ] Нет обещаний про ПП, похудение, детокс, «омоложение».
- [ ] Нет слов «шедевр», «невероятный», «просто бомба».
- [ ] Нет воды: убрал абзац — смысл не потерялся ⇒ абзац лишний.
- [ ] Вопрос в конце — узкий, на который легко ответить одним словом.
- [ ] Теги 4–6 шт., один брендовый: `#cookrate`.
- [ ] Гречка/латиница не полезла в текст (`git grep -nE "[A-Za-z]{6,}"` по файлу).

## Картинки

- [ ] Анжела, та же причёска, фартук, кухня, та же тарелка (`angela.md`).
- [ ] Еда в кадре крупнее лица, 30–40 % высоты кадра.
- [ ] Блюдо готовое и глянцевое; не процесс на разделке.
- [ ] Подпись снизу слева: капс, «ёлочки», 3–5 слов, тяжёлый узкий гротеск, белая.
- [ ] Формат: 16:9 обложка, 9:16 вертикаль; текст не по краям (Дзен кропнет).
- [ ] Проверка на 40 px в ширину: угадывается, что за блюдо.
- [ ] Нет чужих цветов (красный/синий/кислотный) в одежде и фоне.

## Видео

- [ ] 0–4 сек — готовое блюдо и крючок-возражение, не доска с ножом.
- [ ] План не дольше 4 секунд, звук еды не заглушён музыкой.
- [ ] Субтитры есть, шрифт тот же, что на обложке.
- [ ] В конце — призыв сохранить в «Моё», а не «поставьте лайк».
- [ ] Цена порции показана титром.

## Публикация

- [ ] Дата/время: будни, 17:00–20:00 по местному аудитории.
- [ ] Ссылка на ролик вставлена (через 2–3 часа после старта ленты, если статья большая).
- [ ] Статус файла в репозитории переведён в `published`, номер совпадает с номером публикации.
- [ ] Текст из Дзена перенесён в `published/NNN-*.md` — архив обязан совпадать с эфиром.
- [ ] Заметка в `content-plan.md`: что пошло лучше плана, что хуже (одна строка).
