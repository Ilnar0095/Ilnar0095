# Как создать своего бота: 5 шагов

Короткая версия. Подробная — в `SETUP-telegram.md`, но начните отсюда.

## Сначала главное: бот = две вещи

1. **Регистрация в Telegram** — вы говорите отцу всех ботов: «у меня будет бот, зови его
   вот так». Он выдаёт **токен** — ключ, по которому программа имеет право писать от имени
   бота. Это 2 минуты, делается в телефоне, никакого кода.
2. **Программа, которая отвечает** — тот самый `bot/` из этого репозитория. Она крутится на
   вашем компьютере. Пока она запущена, бот отвечает; закрыли окно — бот молчит.

Ничего «публиковать в Telegram» не нужно: бот появляется у вас в чатах сразу после шага 1.
Дальше просто нажимаете двойной клик (шаг 4) — и он оживает.

---

## Шаг 1. Создать бота (в телефоне, 2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) → **Start**.
2. Напишите `/newbot`
3. Он спросит имя — введите: `COOKRATE Необычная Кухня` (можно любое, можно по-русски).
4. Потом спросит username — введите латиницей, обязательно с `bot` на конце:
   `cookrate_kuhnya_bot`
   (если займут — `cookrate_kuhnya_1_bot`).
5. BotFather пришлёт ответ со строчкой:

```
0123456789:AAH1Ks7mVQ...   ← ЭТО ТОКЕН
```

Нажмите на неё правой кнопкой/долго — скопируется. ⚠️ Токен = пароль от бота.
В чат, в почту, в скриншоты его не отправляйте.

**Готово, бот создан.** Он уже есть в Telegram, ищется по `@cookrate_kuhnya_bot`,
но пока молчит — ему нечем отвечать.

## Шаг 2. Скачать папку с «мозгами»

* Стоит `git`: `git clone -b arena/ff89cd13-ilnar0095 https://github.com/Ilnar0095/Ilnar0095.git cookrate`
* Без git: на странице репозитория **Code → Download ZIP** (сначала переключите ветку
  на `arena/ff89cd13-ilnar0095`), распакуйте в `C:\\cookrate`.

## Шаг 3. Поставить Python (один раз)

[python.org/downloads](https://www.python.org/downloads/) → при установке
**поставить галочку «Add python.exe to PATH»** ← из-за неё чаще всего всё и ломается.

## Шаг 4. Двойной клик

В распакованной папке: `bot\\` → **два раза по `start-bot.bat`**.

Он сам создаст окружение, сам догрузит нужные библиотеки (первый запуск 1–2 минуты),
сам спросит токен (вставьте правой кнопкой), сам проверит его и запустит бота.
Увидите `🍳 COOKRATE bot запущен` — окно не закрывайте, это и есть работающий бот.

Уже поставили раньше? Тогда `start-bot.bat` просто запускает бота.

## Шаг 5. Написать своему боту

Telegram → найти `@cookrate_kuhnya_bot` → **Start** → он покажет ваш id и предложит меню.
Пробная команда:

```
/пост Мандарины в беконе
```

Пришлёт текст + отчёт проверки. Кнопка **💾 В dzen/next/** сохранит черновик файлом в
папку `dzen/next/`, и вы положите его в Дзен обычным копированием.

## Что происходит после

| Хочу | Как |
|---|---|
| Чтобы писал готовый текст, а не каркас | в `bot/.env` дописать `LLM_API_KEY=sk-…` и `LLM_MODEL=gpt-4o-mini`, перезапустить двойным кликом |
| Картинки-иллюстрации | там же `IMAGE_PROVIDER=openai` (или `replicate` + его токен) |
| Обложки и тизеры прямо на Windows | `winget install Gyan.FFmpeg`, перезапустить |
| Бот отвечал, даже когда ноутбук закрыт | VPS от ~200 ₽/мес: `SETUP-telegram.md`, шаг 7.3 |

## Если не заводится

| Вижу | Делаю |
|---|---|
| «Python ne naiden» | вернитесь к шагу 3, поставьте галочку PATH, затем снова двойной клик |
| Telegram ответил 401 / Unauthorized | токен скопирован не целиком (нужны обе части через `:`) или бота пересоздали → `/revoke` у BotFather |
| Бот молчит на `/start` | закрыто окно запуска; откройте снова |
| Не знаю, живой ли токен | `python -m bot --check-token` — должен ответить «✅ токен рабочий. Бот: …» |
| Черновик не появился в `dzen/next/` | вы запустили `start-bot.bat` из другой копии репозитория; проверьте, что папка та |

Одна команда для самопроверки сборки (без интернета и без Telegram):
`python bot\\install.py --check`
